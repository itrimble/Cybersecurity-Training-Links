# Website direction and quality bar

Standalone game site for prismshift.remnantsecurity.com, authored inside the user's existing website repo without changing the main React site or its deployment. Audience: players discovering Ian's non-commercial iPhone/Apple TV homebrew puzzle game. Goal: make the real game and matching/timeline identity understandable, let visitors see actual gameplay and15 material skins, explain available accessibility choices, and truthfully mark current development status. No release date, public download, App Store listing, or sustained4K60 claim is supplied.

First viewport: an indigo crystal-game surface, Unbounded display + Space Grotesk body using game fonts, cyan highlight, a real phone gameplay capture opposing the Build the light/Break the darkness headline, working Watch/Explore anchors. Content-led gallery is a horizontally scrollable strip of actual captures with a combined atlas fallback. The native video uses controls (no autoplay) and includes the active Awakening soundtrack, added to footage without live gameplay SFX. Closing returns to the existing Remnant site.

Signature interaction: visitors directly scrub/watch the real Pulse Line footage and move through the15 skin captures; no decorative page motion. Reduced-motion preference removes smooth scrolling/snap. Quality bar:1440desktop and390mobile, no viewport overflow, readable type/contrast, keyboard-visible focus, working local media/anchors, accurate provenance, existing main-site output unchanged.

Existing product truth: game is in development; matching is4-connected networks of3+same-type blocks, cleared by the Pulse Line; Core activates within a valid match and follows its connected chain. Accessibility/device acceptance remain ongoing and the page says so. Continue semantics in the separate TV redesign were confirmed campaign-progress only by the user.

The captures may include tutorial hints/transient clear effects and use seeded QA/no tide. Material names differ from some original campaign/track names (Biolume/Bloom etc); this is recorded in the README and source provenance. Consider whether the public gallery needs clearer naming for this distinction.

## Direction contract

THESIS: Show the real rhythm puzzle and its crystal materials immediately, then
explain the3+network/Pulse Line interaction through actual media.

OWN-WORLD: Adopt the game's existing indigo field, cyan selection/light, Unbounded
display and Space Grotesk body, and original BrandPrism. This is brand reuse, not a
new generated crystal world. Rounded controls and phone captures carry its grammar.

STORY: Visitors understand what they connect, when the sweep clears, and how skins
change; they watch actual footage and inspect the material strip. They see that the
homebrew build is still in development and no download is claimed.

FIRST VIEWPORT: Tracked brand/navigation above left-aligned headline/body/actions;
real portrait gameplay on the right. Mobile stacks the same content without clipping.

FORM: Code-led standalone static extension of the existing game identity. The initial
layout was agent-selected without a seed roll. The user explicitly approved the
completed preview on October14: “Keep the current preview.” The user-pinned title/pause references belong to the game
UI and inform reused brand, not a website comp.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish
review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
