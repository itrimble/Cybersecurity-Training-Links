# Prism Shift website product context

A non-commercial homebrew crystal rhythm puzzle game by Ian Trimble, in development
for iPhone and Apple TV. The user requested its website inside this repository at
prismshift.remnantsecurity.com. Visitors are prospective players seeking gameplay,
world/skin variety, music identity, and readable accessible controls.

Primary outcome: understand the game and watch its actual development footage.
No public download, store listing, pricing, release date or performance acceptance
is supplied. The page must not invent those claims. Matching is orthogonal groups
of3+same-type crystals, charged until the Pulse Line crosses them. It has15 material
skins and a62-stage journey. Core chains are connected, not board-wide.

Visual assets/fonts are reused from the game. Media must be authentic captures with
accurate material/track labels and QA provenance. Main remnantsecurity.com output
and existing storefront/content must survive. Deployment uses a separate host root;
current DNS and hosting auth are unresolved. Accessibility and device acceptance
remain in progress. Existing game facts supply this context; no separate website
marketing questionnaire or user-approved website comp was obtained.
