# CyberPath - Cybersecurity Career Training Guide

An interactive website to help students and professionals navigate cybersecurity career paths, find training resources, and plan their certification journey.

## Live Website

Visit the website: [CyberPath](https://itrimble.github.io/Cybersecurity-Training-Links/)

## Features

### Career Path Explorer
Choose from 12 different cybersecurity career paths:
- **Security Analyst / SOC Analyst** - Monitor and respond to security threats
- **Penetration Tester / Ethical Hacker** - Find vulnerabilities before attackers do
- **Security Engineer** - Build and maintain security infrastructure
- **Incident Responder / DFIR** - Investigate and recover from breaches
- **Security Architect** - Design enterprise security solutions
- **GRC Analyst** - Manage compliance and risk
- **Cloud Security Engineer** - Secure cloud environments
- **Application Security Engineer** - Integrate security into development
- **Threat Intelligence Analyst** - Research and track threat actors
- **Red Team Operator** - Conduct advanced adversary simulations
- **Malware Analyst** - Reverse engineer malicious software
- **CISO / Security Manager** - Lead security programs

### Interactive Career Quiz
Answer 5 questions to discover which cybersecurity role matches your interests and skills.

### Certification Roadmap
Navigate certifications from entry-level to expert:
- **Entry Level**: Security+, CC, eJPT, BTL1
- **Intermediate**: CySA+, CEH, PNPT, GSEC, AWS Security
- **Advanced**: CISSP, OSCP, CISM, CCSP, GREM

### Free Training Resources
Curated collection of free learning platforms:
- TryHackMe
- Hack The Box Academy
- SANS Cyber Aces
- Fortinet Training Institute
- PortSwigger Web Security Academy
- Professor Messer
- And many more...

### Hands-on Labs
Practice environments for all skill levels:
- TryHackMe & Hack The Box
- Blue Team Labs Online
- CyberDefenders
- PicoCTF
- OverTheWire Wargames
- VulnHub

### Additional Resources
- Community forums and Discord servers
- Security news and blogs
- Essential tools (Kali, Burp Suite, Wireshark)
- Government resources (CISA, NIST, NICCS)

## Local Development

1. Clone the repository:
```bash
git clone https://github.com/itrimble/Cybersecurity-Training-Links.git
cd Cybersecurity-Training-Links
```

2. Open `index.html` in your browser, or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

3. Visit `http://localhost:8000`
